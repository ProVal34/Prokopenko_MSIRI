1. Отличие коллайдера от коллизии.
Коллайдер считывает касание, а коллизии коллизия может считывать скорость воздействия, точки соприкосновения с объектом и реагировать на них.
2.Отличие while от do while.   
Цикл while повторяет блок кода до тех пор, пока указанное условие остаётся истинным, а do while сначала выполняет потом проверяет. 
3. Методы web запросов.
GET. Используется для запроса данных с сервера.
POST. Применяется, когда клиент отправляет данные на сервер.
PUT. Используется для полного обновления данных.
PATCH. Похож на PUT, но применяется для частичного изменения.
DELETE. Говорит серверу, что ресурс нужно удалить.
4. Когда используется OnCollision и OnTrigger.
OnCollision используется, когда нужно физическое взаимодействие.
OnTrigger используется, когда нужно отслеживать вход/выход объектов, не влияя на их движение.
5. Для чего нужен интерфейс Input. 
Интерфейс Input нужен для того, чтобы пользователь мог вводить данные и их показатели.
