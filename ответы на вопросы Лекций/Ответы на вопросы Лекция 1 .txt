1. Чем класс отличается от объекта?
Класс- описывает состояние объекта
а объект это взаимодействие данных и поведений 
2. Что хранит переменная класса?
Переменная класса хранит данные конкретного объекта и его состояния
3. что произойдет при обращении к члену через null ссылку
При обращении через null ссылку так как сама ссылка показывает отсутствие переменной то вероятно мы получим пустую строку
4. Зачем объединять поля и метод в одном классе
для упрощения программирования для того чтобы можно было не вызывать сначала поле потом метод

1.Зачем скрывать поля класса?
поля класса скрывают для упрощения восприятия а также в некоторых случаях для защиты данных
2. Чем свойство отличается от поля?
Поле это хранилище, а свойство механизм доступа
3. что произойдет если не объявить ни одного конструктора
будет автоматически создан самой программой
4. как конструктор связан с инкапсуляцией
благодаря инкапсуляции и конструктору можно создать надежный класс, конструктор гарантирует корректное создание данных  
5. можно ли изменить свойство только для чтения после создания объекта
нет нельзя, однако с помощью некоторых инструментов можно создать клон который можно будет открыть для чтения
